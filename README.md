# JavaScript Assignments & Capstone Project

## 📌 About the Project

This repository contains JavaScript practical assignments designed to demonstrate fundamental JavaScript concepts, including variables, data types, operators, conditional statements, loops, functions, arrays, and objects.

## 📚 Assignments

1. **Variables, Data Types, and Console Operations** – Demonstrates variables, data types, and console output.
2. **Operators, Expressions, and Input Handling** – Calculates tips and total bills using user input and arithmetic operators.
3. **Conditional Logic Implementation** – Evaluates scores, assigns grades, and determines pass or fail status.
4. **Loop Control Structures** – Demonstrates loops, multiplication tables, and `break` and `continue` statements.
5. **Function Architecture and Scope** – Uses regular functions, arrow functions, and default parameters to calculate rectangle areas.
6. **Arrays, Objects, and Core Methods** – Uses `forEach()`, `filter()`, and `map()` to process product information.

## 🚀 Capstone Mini Project

**Interactive Product Inventory & Analytics Dashboard**

A JavaScript application that allows users to add products, categorize them by price, calculate total inventory value, filter affordable products, and generate inventory reports.

## 🛠️ Technologies Used

* HTML
* JavaScript
* Visual Studio Code
* Web Browser

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open the HTML file in a web browser.
4. Follow the prompts and check the browser console for output.
